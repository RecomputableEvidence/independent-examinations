# Claim boundaries — initial registry

| Subject | Permissible claim | Excluded inference |
| --- | --- | --- |
| Public repository | Source, submissions, and review history can be inspected within published scope. | A public host or author owns independent truth. |
| CI success | Committed tool tests passed in the observed runner. | Examiner independence, absence of shared error, or system qualification. |
| Receipt comparator | Two supplied receipts agree or differ in recorded outputs. | Either receipt is correct about external facts. |
| Historical COMP-003 | Its registered synthetic results and later adverse findings were reported in prior archives. | Complete reviewer equivalence, reliable graph semantics, or actual Lens Methods advantage. |
| COMP-004 R1 | **PROPOSED / NOT_RUN.** | Any defect has been fixed or re-examined. |
| COMP-004 R2 | **CONTRACT PROPOSED / NOT_RUN.** | Externally authenticated actor/grant/evidence or operational effect. |
| Real issuer authority | **UNVERIFIED.** | Source seal, grant, transfer, integration, or deployment permission. |
| MPI-01/MPI-02 screening | A model's identity, task-readiness, and decision-account declarations satisfy or fail a specified formal screen. | A self-declared model ID is authenticated, self-confidence is calibrated, cited evidence is true, or a model is independently qualified. |

**Overall:** `PUBLIC_INFRASTRUCTURE_DRAFT / COMPARATIVE_EFFECTIVENESS_NOT_ESTABLISHED / EXTERNAL_AUTHORITY_UNVERIFIED / OPERATIONAL_ADMISSION_WITHHELD`.

This document is updated by versioned, reviewed records. A discovered defect is retained even if a later implementation repairs it.
